# Mhserver Client

Клиент для [mhserver](https://github.com/braginantonev/mhserver).

## Установка
### Linux
#### Arch
Пакет доступен на `AUR`. Вы можете установить его вручную, либо с помощью пакетного мэнеджера, например `yay`.
``` bash
yay -S mhserver-client
```
Если пакет на `AUR` недоступен, вы можете установить пакет вручную. Скачайте пакет из ассетов [последнего релиза](https://github.com/braginantonev/mhserver-client/releases/latest).
Например, для версии 1.0.1 - это файл [mhserver-client-1.0.1-1-x86_64.pkg.tar.zst](https://github.com/braginantonev/mhserver-client/releases/download/v1.0.1/mhserver-client-1.0.1-1-x86_64.pkg.tar.zst):
``` bash
cd /tmp
wget https://github.com/braginantonev/mhserver-client/releases/download/v1.0.1/mhserver-client-1.0.1-1-x86_64.pkg.tar.zst
sudo pacman -U mhserver-client-1.0.1-1-x86_64.pkg.tar.zst
```

#### Ручная установка
Для данного способа скачайте билд из [последнего релиза](https://github.com/braginantonev/mhserver-client/releases/latest). 
Хоть и дополнительных зависимостей не требуется, возможно вам придётся установить `openssl`.

Скачанным билдом уже можно пользоваться, расположите его где удобно и создайте символическую ссылку:
``` bash
ln -s путь_до_исполняемого_файла куда_вы_хотетите_сохранить_ссылку
```
Рекомендую расположить исполняемый файл в `/opt/mhserver-client`.

### Windows
Скачайте установщик из [последнего релиза](https://github.com/braginantonev/mhserver-client/releases/latest) и запустите его. 
Программа автоматически установится на ваш компьютер.

## Использование
### Подключение к серверу
При первом запуске, либо при отсутствии связи с первоначально указанным сервером, клиент потребует указать адрес вашего сервера.
Это может быть как домен, так и `IP` адрес с портом.

Сервер работает только по протоколу `https`, что нужно указать в адресе сервера:
```
https://my.server.ru
```

#### IPv6
Для использования 6 версии `IP`, адрес обязательно нужно оборачивать в квадратные скобки:
```
https://[fe80::2e31:aac1:3a8e:12]:30543
```

> [!IMPORTANT]
> Для использования этого протокола, удостоверьтесь, что на вашем маршрутизаторе включена поддержка этого протокола и что компютер имеет свои `GUI` 
> и `local-link` адреса для глобального и локального доступа, соответственно.

### Регистрация
Помимо логина и пароля, для регистрации вам необходим ключ регистрации. О том, как его получить вы можете узнать в репозитории [сервера](https://github.com/braginantonev/mhserver).

## Политика релизов
### Мажорные обновления
Обновление мажорной версии идёт вслед за подобным обновлением [mhserver](https://github.com/braginantonev/mhserver). 
Единственное отличие - нумерация мажорных обновлений клиента всегда меньше на 1 версии сервера.

Клиент не поддерживает работу с сервером чья мажорная версия отличается от поддерживаемой.
При попытке использовать клиент в подобной ситуации - программа оповестит вас об обновлении, либо об устарелости сервера.

### Минорные и патчевые обновления
Обычные обновления функционала клиента. Гарантируют совместимость с сервером.
При обнужении подобного обновления, программа оповестит пользователя об его наличии.
